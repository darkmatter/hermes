# Hermes configuration template

Copy-paste defaults for [Hermes Agent](https://github.com/NousResearch/hermes-agent).

## Files

- `config.yaml` configures models, tools, memory, and personalities.
- `SOUL.md` contains an example agent persona.
- `env.example` documents required and optional provider environment variables.

## Usage

Copy the files you want into your Hermes configuration directory, then adapt them
for your provider, operating system, and secret-management solution. Do not commit
real credentials or generated environment files.

## Contributing

This repository is synchronized from its private source of truth. Submit changes
there or open an issue describing the proposed template improvement.
