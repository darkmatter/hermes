# Agent-first billing investigation

Cooper is **not** the researcher for failed payments / renewals.

## Do

1. Open official billing portal yourself (Studio CUA / known URL — never untrusted email links)
2. Read failure reason, amount, plan, method suffix
3. Comment evidence on kanban
4. Stage or poll feed Pay/Don't-pay (`feed-d1-intake.md` / skill `feed-decisions`)
5. On Pay: charge gate; SA `op` only (`op-service-account.md`)

- Ask “what did the console show?”
- Ask Cooper to log in and paste status
- Use biometric/bare `op` or personal agenix token
- Clipboard “Copy for Hermes”
