# Source-discipline checklist

Use this before drafting or revising personal writing.

## One designated source

When Cooper names one source, use that source alone for voice, framing, and factual support. Do not blend in examples from other personal notes, public posts, or nearby documents just because they appear more obviously relevant.

## Similar titles are a trap

If Linear or another system contains multiple documents with similar titles, establish the exact one before drafting. Prefer an explicit document ID or the opening sentence/section title as confirmation. If Cooper corrects the choice, restart source analysis from the corrected document.

## Reference vs. destination

The requested destination can be a personal Obsidian vault even when `OBSIDIAN_VAULT_PATH` points to a team vault. Keep source selection and note placement as separate decisions.

## Revision response

"Not quite right" generally means the issue is structural or tonal, not copyediting. Rebuild the draft from the authorized reference's cadence and sequence before tweaking sentences.
