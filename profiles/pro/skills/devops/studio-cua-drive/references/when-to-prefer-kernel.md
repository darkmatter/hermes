# Kernel vs Studio cua for public booking sites

For **public** aa.com search / fare select / summary (no need for Studio cookies):

- Prefer **`kernel-browsers`** (cloud Playwright, himitsu `kernel-api-key`). Faster Material form + fare-ladder control in practice.

Stay on **Studio cua** when:

- Logged-in AAdvantage / cookies on Studio Chrome matter
- Cooper says drive Studio explicitly
- Kernel unauthenticated and he blocks login

Still never drive Studio via Pro Screen Sharing `computer_use`.

AA credit: clean form (Last name + DOB + 13-digit) can stick and still return empty — that means **number wrong**, not “cua broken.” Spoken Levi digits must be discarded if user confirms wrong.
